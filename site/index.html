picoclock

Rust firmware for the Waveshare Pico-Clock-Green. It sets itself by NTP or authenticated NTS, serves a web page over HTTPS, takes signed updates, and can use a DCF77 receiver as a second time source.

What it does

Time you can trust

NTP, NTS (RFC 8915) with TLS 1.3, and a DCF77 radio module. Pick an ordered list with fallbacks, or let the sources vote. The RTC holds UTC and is set on the second boundary.

Timezones with DST

An IANA name (486 built in), a POSIX rule, or a lookup by your public IP. Daylight saving needs no sync.

Configuration three ways

A web page (HTTPS on the Pico 2 W), a USB serial terminal, and the three buttons for everyday settings. One validator for all three.

Signed updates

Releases are Ed25519-signed and swapped in by a bootloader that can go back. The clock checks for a release on request and installs only after you confirm.

Also

Morse-code chime, an NTP server for your LAN, up to 8 WiFi networks, alarm, buzzer, light-sensor dimming, a hardware watchdog.

Open source

AGPL-3.0-or-later, built on Embassy. Every requirement is traced to a test or a dated hardware run.

What you need

ClockWaveshare Pico-Clock-Green
ControllerRaspberry Pi Pico 2 W (recommended: HTTPS, NTS with RSA chains, hardware random numbers) or Pico W (plain HTTP only)
OptionalDCF77 module (Pollin DCF1). A u-blox NEO-M9N GPS is built and in testing, not in a release yet.

Install

Download the .uf2 for your board from the latest release, hold BOOTSEL while plugging the Pico in, and copy the file to the drive that appears. Then connect over USB and set up WiFi:

set wifi1_ssid MyNetwork
set wifi1_password MyPassphrase
set timezone Europe/Berlin
save

Later versions install over the air from the web page or the terminal; the .pcu files in each release are the signed update packages. Checksums are in SHA256SUMS. The README covers building from source, NTS, HTTPS, the buttons and the limits.
